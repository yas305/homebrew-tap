# CopyClip Homebrew tap

[CopyClip](https://copyclip.app) is a free clipboard history for macOS with actions for whatever you copy: download videos from links, convert and crop images, trim video and audio, copy text from screenshots, and clean tracking from links.

```bash
brew install --cask yas305/tap/copyclip
```

CopyClip updates itself through Sparkle, so `brew upgrade` isn't needed to stay current. To remove it and its settings:

```bash
brew uninstall --zap --cask copyclip
```

Requires macOS 14 Sonoma or later. Runs on Apple silicon and Intel.
